# PASSIFY - NSCC INET 2100 TERM PROJECT SOLUTION

### Description
A web application that allows event organizers to manage their events and attendees.
The application is designed to be user-friendly and easy to use.

### Stack

| Component     | Stack                                 | Description                |
|---------------|---------------------------------------|----------------------------|
| Infrastructre | Github, Github Actions, Azure, Vercel | Hosting and Infrastructure |
| Backend       | C#, ASP.NET,  MSSQL                   | Management Portal          |
| API Layer     | TypeScript, Node.js, MongoDB          | Intermediary Web API       |
| Frontend      | JavaScript, React, SCSS               | Client-facing Web UI       |

## Project Structure
```
.
├── PASSIFY             # Backend Asp.NET MANAGEMENT PORTAL
├── PASSIFY-WEB-API     # Intermediary Node.JS API Layer      
└── PASSIFY-WEB-UI      # Client facing React Web UI Layer
```
