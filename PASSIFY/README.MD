### PASSIFY - ASP.NET MANAGEMENT PORTAL

```text
.
├── Migrations                      # Entity Framework database migration files
├── Controllers                     # MVC controllers handling HTTP requests and business logic
├── Data                            # Database context and data access layer
├── Models                          # Data models and entity classes
├── Views                           # Razor view templates for UI rendering
│   ├── Account                     # User authentication and account management views
│   ├── Activities                  # Activity listing and management views
│   ├── Categories                  # Category management views
│   ├── Home                        # Home page views
│   ├── Organizers                  # Organizer management views
│   ├── Purchases                   # Purchase/ticket transaction views
│   ├── Shared                      # Shared layout and partial views
│   ├── _ViewImports.cshtml         # Global view imports and namespaces
│   └── _ViewStart.cshtml           # Default layout configuration
├── wwwroot                         # Static web assets (client-side files)
│   ├── assets                      # Images, icons, and SVG files
│   ├── css                         # Stylesheets
│   ├── js                          # JavaScript files
│   ├── lib                         # Third-party libraries
│   └── favicon.ico                 # Website favicon
└── Program.cs                      # Application entry point and configuration
```
